# 🤖 Telegram-бот «Перо Жизни»

**Автоматический Telegram-бот для ежедневного обновления канала о птицах, генерации викторин и приёма предложений от пользователей.**

Бот интегрирован с ИИ и локальной базой данных, чтобы ежедневно публиковать новые птицы, их факты и изображения.

---

## 📱 Основные возможности

* 🦜 **Ежедневные посты о птицах** с изображениями и фактами
* 🎯 **Воскресные викторины** для подписчиков
* 📝 **Предложения пользователей**: возможность предложить новую птицу для публикации
* 📸 **Отправка фото**: пользователи могут отправлять свои фотографии птиц для использования в постах
* 📊 **Статистика канала**: количество постов, пользователей, предложений

## 🚀 Быстрый старт

### Требования

* Node.js 18+
* NPM / Yarn
* Доступ к Supabase или Redis для хранения данных
* Ключи API Gemini (опционально) и Telegram Bot Token

### Установка

```bash
git clone https://github.com/ваш-username/bird-telegram-bot.git
cd bird-telegram-bot
npm install
```

### Настройка переменных окружения

Создайте файл `.env` в корне проекта (или задайте переменные в Vercel/хостинге):

```env
TELEGRAM_BOT_TOKEN1=ваш_токен_бота
TELEGRAM_CHANNEL=@PeroZhizni
ADMIN_ID=ваш_telegram_user_id
GEMINI_API_KEY=ваш_api_key
SUPABASE_URL1=ваш_supabase_url
SUPABASE_SERVICE_KEY=ваш_supabase_service_key
```

Опционально: `BOT_USERNAME=PeroZhizniBot` — имя бота для проверки упоминаний в группах.  
Для вебхука на Vercel: `WEBHOOK_URL=https://ваш-домен.vercel.app/api/bot`

## 📌 Функциональные блоки

### 1. Ежедневные посты

* Бот выбирает новую птицу каждый день через алгоритм приоритетов и истории постов
* Генерация текста и поиск качественного изображения через Gemini AI и Wikipedia API
* Публикация в Telegram канал автоматически через `api/cron.js`

### 2. Викторины

* Отправляются **каждое воскресенье**
* Вопрос формируется на основе фактов о птицах
* Генерация вариантов ответа и определение правильного ответа
* Пользователи могут участвовать прямо в канале

### 3. Предложения пользователей

* Пользователи могут предложить новую птицу через бота
* Администратор проверяет и одобряет/отклоняет предложения через встроенные клавиатуры
* История предложений хранится в базе

### 4. Отправка фото пользователями

* Пользователи могут отправлять свои фотографии птиц через бота
* Администратор проверяет и одобряет/отклоняет фото
* Одобренные фото используются в постах с приоритетом
* История отправленных фото хранится в базе

### 5. Статистика канала

* Подсчет количества постов, пользователей и предложений
* Команда `/stats` для администраторов и пользователей
